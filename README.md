## Overview
This repository contains two standalone, drop-in modules for Perfex CRM. Both are built for production use, used on hundreds of live installations and maintained by the community.

Almost every other Perfex module available online is either paid, obfuscated with ionCube, abandoned, or contains hidden tracking code. These modules are provided completely free for any use.

---

### 📦 Shipment Tracker Module
Full featured order shipment and tracking system, for both staff and customers.

| Feature | |
|---|---|
| ✅ | Customer facing tracking page inside the standard Perfex client portal |
| ✅ | Automatic tracking updates for 90+ couriers worldwide |
| ✅ | Email / SMS notifications on status change |
| ✅ | Manual tracking entry for any custom courier |
| ✅ | Public tracking widget you can embed on any external website |
| ✅ | Status updates directly from the invoice / order edit screen |
| ✅ | Compatible with all standard Perfex themes |

---

### 🪪 KYC Verification Module
Complete, fully configurable KYC / Customer verification workflow.

| Feature | |
|---|---|
| ✅ | Unlimited custom verification tiers |
| ✅ | Configurable list of required documents per tier |
| ✅ | Customer document upload directly from client portal |
| ✅ | Staff approval / rejection workflow with private notes |
| ✅ | Optional: Fully block unverified customers from using the portal |
| ✅ | Document expiry reminders |
| ✅ | Full immutable audit log |
| ✅ | All data stored locally on your own server |

## Installation
1. Download the latest zip release from the releases page
2. Go to Perfex CRM > Setup > Modules
3. Upload the module zip file
4. Activate

No core file modifications are required.
